# Orbasker Tap

## How do I install these formulae?

`brew install orbasker/tap/<formula>`

Or `brew tap orbasker/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "orbasker/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
